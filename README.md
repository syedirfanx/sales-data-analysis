# Sales Data Analysis

A complete exploratory data analysis (EDA) project on a sales dataset using Python, Pandas, and Matplotlib.
This project analyzes sales trends, pricing distribution, customer locations, correlations between variables, and visual insights from business sales data.

## Project Overview

The goal of this project is to perform exploratory data analysis on a real-world sales dataset to discover:

- Sales patterns
- Product pricing behavior
- Customer distribution by city and country
- Relationships between sales variables
- Statistical summaries and correlations
- Visual insights through plots and charts

The analysis was performed using:

- Python
- Pandas
- Matplotlib

## Dataset Information

The dataset contains 2823 rows and 25 columns related to customer orders and sales transactions.
